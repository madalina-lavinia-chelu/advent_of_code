## Working with the solutions

Choose a year and day from the index, then open its source folder. Run the Java entry points from the repository root so their relative input paths resolve correctly.

- **Java:** projects use Maven. Check the selected project's `pom.xml` for its Java version and run its entry point from your IDE. The Java aggregator (`Java/pom.xml`) targets Java 17; older modules retain their own settings. From the repository root, use `mvn -f Java/pom.xml compile` to build the Java projects.
- **C / C++:** compile the selected source file or open the corresponding project in your IDE. Some days contain separate programs for Part 1 and Part 2.
- **Inputs:** check the selected program's file path before running it. Input locations vary between projects.
